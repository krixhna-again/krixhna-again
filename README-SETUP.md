# Krishna's GitHub Profile README — Setup

## Folder structure

```text
krixhna-again/
├── README.md
└── assets/
    ├── fire.gif
    ├── github-loop.gif
    └── cozy-ending.jpg
```

## Install it on your GitHub profile

1. Open the repository named exactly `krixhna-again` (your profile README repository).
2. Replace its `README.md` with the provided `README.md`.
3. Create an `assets` folder in that repository.
4. Upload all three files from `assets/` with the exact filenames shown above.
5. Commit the changes and open your GitHub profile.

## Important

Keep the asset filenames and folder name exactly as provided. The README uses relative paths such as `./assets/github-loop.gif` and `./assets/fire.gif`, so the files must be committed to the same profile repository.

The typing animation is provided by Readme Typing SVG and loops continuously. The GitHub statistics and activity graph are generated dynamically from your public GitHub data.

No broken Discord invite has been included in this version.
